# ЭхоЧат LIVE

Озвучка чата TikTok LIVE живыми нейро-голосами. Тёмное приложение для Windows: подключение по нику, лента чата, счётчики, виджеты для OBS и TikTok LIVE Studio, донаты Каспи.

## Скачать

Последняя версия: [Releases](../../releases/latest). Для установки скачайте файл с «Setup» в имени. Приложение само проверяет обновления и обновляется по кнопке.

## Тарифы

Lite бесплатный, Pro открывает «Виджеты» и «Донаты Каспи». Подробности и покупка внутри приложения, вкладка «Лицензия».
