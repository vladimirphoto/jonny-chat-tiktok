# ЭхоЧат LIVE

Озвучка чата TikTok LIVE живыми нейро-голосами Microsoft (10 голосов: Светлана, Дмитрий и мультиязычные Ава, Эмма, Вивьен, Серафина, Эндрю, Брайан, Реми, Флориан) — бесплатно, без ключей и карты в тёмном современном приложении для Windows.

- Подключение по нику автора, лента чата, счётчики зрителей / лайков / подарков / подписок
- Озвучка сообщений, подарков и новых подписок
- Фильтры: команды, ссылки, повторы, мат, упоминания, эмодзи, только русский
- Скорость, тон и громкость голоса; пауза и «пропустить»
- Нейро-голоса работают через интернет; если синтез не удался, сообщение просто пропускается

## Запуск из исходников

```bash
npm install
npm start
```

## Сборка exe (Windows)

```bash
npm install
npm run dist
```

Готовый портативный файл появится в `dist/EchoChat-LIVE-1.0.0.exe`.

## Сборка на GitHub

Workflow `Build Windows exe` собирает exe при каждом пуше в `main` (вкладка Actions → артефакт `EchoChat-LIVE-exe`).
Чтобы получить exe в Releases, создай тег: `git tag v1.0.0 && git push --tags`.

## Обновление из приложения

Кнопка «Проверить обновления» (слева внизу, значок обновления) смотрит последний релиз на GitHub. Если версия новее — скачивает exe и заменяет текущий файл, затем перезапускает приложение.
Чтобы выпустить обновление: подними `version` в `package.json` и запушь в `main` — workflow сам соберёт exe и создаст релиз `v<версия>`.

## Виджет чата (v1.5.0)
Вкладка «Виджеты» → скопируй ссылку (по умолчанию `http://127.0.0.1:7878/chat`) и добавь в OBS как «Браузер», в TikTok LIVE Studio — как «Ссылка». Если TikTok не принимает localhost, выбери другой «Формат ссылки»: `127.0.0.1`, `localhost` или IP локальной сети (при выборе IP сервер виджета открывается для устройств в вашей сети).
Чат TikTok и Twitch на прозрачном фоне с лёгкой тенью; настройки: выравнивание (TikTok слева · Twitch справа), иконки платформ, аватарки, подарки, масштаб и высота в %, исчезающие сообщения. Канал Twitch вводится на вкладке «Эфир» (мультистрим): сообщения Twitch читаются анонимно, ключи не нужны.

## Что нового в 1.10.0
- Новая вкладка «Донаты Каспи» (под «Виджетами»): виджет донатов для OBS и TikTok LIVE Studio (имя, сумма, картинка в тему суммы), отдельная страница на GitHub Pages `donate/`, предпросмотр, кнопка «Тест доната» (временная)
- Приём доната: телефон пересылает уведомление Каспи на компьютер по Wi-Fi (HTTP-запрос на секретный адрес из вкладки), приложение разбирает имя и сумму. Кнопка «Проверить приём» отправляет пробное уведомление

- Автопроверка обновлений: через 30 секунд после запуска и раз в 6 часов. Ставится только по нажатию кнопки

## Что нового в 1.9.3
- Кнопка «Пауза» теперь замораживает ленту чата: новые сообщения копятся (на переключателе виден счётчик «Пауза · +N»), не озвучиваются и появляются в ленте, когда пауза снята. Системные сообщения о подключении показываются сразу. Виджет для OBS паузой не управляется
- Вкладка «Фильтры» переписана: названия говорят, что именно делает фильтр («Не озвучивать команды», «Вырезать @упоминания», «Обрезать озвучку до N символов»), у каждого есть пояснение. Фильтры влияют только на озвучку, в ленте остаются все сообщения
