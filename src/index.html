Живые голоса Google

Бесплатно каждый месяц: живые HD-голоса — 1 млн символов, Neural2 — 1 млн, WaveNet — 4 млн. Для 2–3 стримов в неделю по 2–3 часа обычно хватает: 1 млн символов — это около 16 часов речи. Приложение само считает символы и при 90% лимита переходит на Microsoft-голос.

Как получить бесплатный ключ (5 шагов)
  1. Откройте console.cloud.google.com, войдите в Google и создайте проект.
  2. Включите сервис Cloud Text-to-Speech API (APIs & Services → Library).
  3. Подключите оплату (Billing). Google просит банковскую карту, но пока вы в бесплатном лимите, деньги не списываются. Поставьте бюджет-оповещение на 1 доллар.
  4. APIs & Services → Credentials → Create credentials → API key. Скопируйте ключ.
  5. Вставьте ключ ниже и нажмите «Проверить ключ».
Ключ хранится только на вашем компьютере, запросы идут напрямую в Google.
