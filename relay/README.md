# Сервер приёма донатов Каспи

Один сервер на всех пользователей приложения. Нужен хостинг с PHP 7.4+ и HTTPS, база данных не нужна.

## Развернуть (один раз)

1. Загрузите папку `relay` на сайт, например в `https://ваш-сайт/echochat/` (файлы `lib.php`, `notify.php`, `poll.php`). Папка `data` создастся сама и закрыта от браузера. На сервере не Apache: закройте `data` вручную.
2. Впишите адрес папки в `assets/relay-url.txt` репозитория, например `https://ваш-сайт/echochat`. Приложения подхватят его сами (проверка раз в 10 минут), новая сборка не нужна.
3. Проверка: откройте `https://ваш-сайт/echochat/poll.php?token=0123456789abcdef0123abcd`, должно ответить `{"ok":true,"items":[]}`.

## Как работает

iPhone → `notify.php` кладёт уведомление в очередь токена → приложение каждые 3 секунды спрашивает `poll.php` → имя и сумму разбирает `kaspi.js`, как и при приёме по Wi-Fi.

В приложении во вкладке «Донаты Каспи» кнопка «Скопировать адрес» отдаёт `https://ваш-сайт/echochat/notify.php?token=ТОКЕН`. Этот адрес вставляют в команду iPhone: действие «Получить содержимое URL», метод POST, тело JSON с ключом `text` (текст уведомления). Подойдёт и GET с `&text=` в конце, как у kzdon.

## Безопасность

Токен (24 символа) создаёт приложение, на сервере хранится только его хэш. Лимит 40 уведомлений в минуту на токен, уведомления живут 5 минут. Токен нельзя показывать на стриме: по нему можно прислать фальшивый донат, банк уведомления не подтверждает.
