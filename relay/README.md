# Сервер-посредник для донатов Каспи (через интернет)

Нужен хостинг с PHP 7.4+ и HTTPS. Базы данных не нужно.

1. Загрузите папку `relay` на сайт, например в `https://ваш-сайт/echochat/` (должны лежать `lib.php`, `notify.php`, `poll.php`). Папка `data` создастся сама и закрыта от просмотра из браузера; если сервер не Apache, закройте её вручную.
2. В приложении: «Донаты Каспи» → включите приём → «Через интернет» → вставьте адрес папки. Приложение покажет ссылку для команды iPhone.
3. В команде iPhone одно действие «Получить содержимое URL», метод GET, адрес:

   `https://ваш-сайт/echochat/notify.php?token=ТОКЕН&bank=kaspi&text=<текст уведомления>&app=<приложение>&ttl=<название>`

   Текст, приложение и название вставляются переменными из уведомления через «Кодировать URL», как в примере с kzdon.kz.
4. Автоматизация на iPhone: уведомление Kaspi.kz → «Немедленно» → запустить команду.

Как это работает: iPhone → `notify.php` кладёт уведомление в очередь токена → приложение каждые 3 секунды спрашивает `poll.php` → разбор имени и суммы тот же, что и при приёме по Wi-Fi (`kaspi.js`).

Безопасность: токен 24 hex-символа создаёт приложение, на сервере хранится только его хэш; не больше 40 уведомлений в минуту на токен; уведомления живут 5 минут. Не публикуйте токен: он же и пароль на отправку донатов.
